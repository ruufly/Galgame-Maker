# 多语言系统 (i18n)

三层语言，各层在其目录下配置 JSON 语言文件（文件名 = 语言码）：

| 层 | 位置 | 内容 |
| --- | --- | --- |
| 框架 | `framework/lang/<code>.json` | 日志/提示/内置 UI 文案，引擎构造时自动加载 |
| 插件 | `framework/plugins/lang/<code>.json` | 插件文案（key 带插件前缀，如 `gallery.button`），插件装载时加载 |
| 游戏 | 项目目录 `lang/<code>.json` | **游戏文本**，检测到目录即启用 |

## 游戏文本占位符 `{@key}`

台词/选项/标题/按钮/设置项/角色场景名中的占位符：

```gal
say producer "{@welcome}"
choice:
    "{@choice_like}" -> like_it
```

**解析顺序**：游戏表 → 核心表 → 原文（脚本可直接引用框架文案，如 `{@dialog.quit.text}`）。

## language 块（主文件声明）

```gal
language
    default: en            # 默认语言 (缺翻译回退)
    en: "English"          # 语言码 -> 设置中显示的名字
    zh-CN: "简体中文"
```

* 游戏语言文件只从列出的语言加载；设置页"语言"项显示语言名字
* 语言写入 `$lang` / `$language` 变量

## 各界面文案的多语言

| 位置 | 方式 |
| --- | --- |
| 台词/选项/标题 caption | `{@key}`（显示时解析） |
| 对话框/菜单文案 (window 块) | `{@key}`（**显示时按当前语言解析**，切换即时刷新） |
| 设置界面 title/label/section/options | `{@key}`；内置项用 `label_key` |
| 分栏 (tab) 显示名 | `settings.section.<值>` 键，未配置原样显示 |
| 角色/场景显示名 | `{@key}`（注册存原文，显示时解析——名字框/鉴赏/场景通知） |
| 结束画面 | `ending.name` / `ending.thanks` 模板 |
| 确认框默认按钮 | `confirm.yes` / `confirm.no` |
| title 默认按钮 | `menu.start` / `menu.load` / `menu.quit` |

**结局名约定**：结局名按**原文记录**（跨存档/解锁比较用），显示时解析——脚本与 gallery 配置写同一个占位符即可，任何语言下解锁判断一致：

```gal
ending {@ending.true_end}            # story.gal
gallery
    unlock_ending: "{@ending.true_end}"   # gallery.gal
```

## UI 图片语言变体

路径含 `{lang}` 占位符时按当前语言替换：

```gal
window
    icon: "materials/title_{lang}.png"   # -> title_en.png / title_zh-CN.png
```

切换语言自动重载（`clear_ui_cache`）。

## 渲染字体

```gal
window
    font: "fonts/Ubuntu-R.ttf"     # 相对脚本目录
    # font: "sys:Microsoft YaHei"   # 系统字体
```

运行时：`engine.apply_font(font)` 立即生效。

## 日志多语言

框架全部日志已键化（约 200 条 `log.*` key）：

```python
log.i("log.script_loaded", path=..., labels=..., objects=..., chars=..., scenes=...)
log.w("log.runtime.sfx_unregistered", line=..., name=...)
log.e("log.core.script_start_failed", exc=...)
```

未接入 i18n 的环境（如启动器早期）显示 key 名，可接受。

## API

```python
engine.i18n.set_lang("en")            # 切换语言 (广播 lang_change)
engine.i18n.t("menu.quit")            # 取文本 (回退默认/原文)
engine.i18n.t("gallery.button", ns="plugin")   # ns: core/plugin/game
engine.i18n.resolve("hi {@name}")     # 替换 {@key} (游戏→核心→原文)
engine.i18n.langs()                   # 可用语言列表
engine.i18n.lang_name(code)           # 语言显示名
```

语言文件格式：`{"key": "文本"}` 或 `{"en": {...}, "zh-CN": {...}}`（多语言合并）。

## 切换语言即时刷新范围

确认框（含按钮）、标题/系统菜单按钮、bar 常驻栏、设置界面（title/label/section/选项值）、正在显示台词的角色名、`{lang}` 图片——均基于原始串重解析。已显示完毕的台词全文不重绘（下一句生效）。
